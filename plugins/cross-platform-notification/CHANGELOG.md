## [1.0.0.0] - 2026-01-08

_First release._

### Added

- Add cross-platform system notifications for Claude Code hook events
- Support for Windows toast notifications via PowerShell
- Support for macOS notifications via terminal-notifier
- Support for Linux notifications via notify-send
- Fallback to console output when native notifications unavailable
- Notification hook integration for Claude Code PostToolUse and other events
